# ЛР3 — список задач

Flutter-приложение для лабораторной работы №3. Задачи сохраняются между запусками через shared_preferences: в браузере используется localStorage, на Android — хранилище устройства.

Реализованы добавление, редактирование, удаление, отметка выполнения, поиск по части названия, фильтры и дата создания. Дополнительные возможности — сортировка по названию и дате создания в двух направлениях, а также локальное сохранение названия, статуса и даты каждой задачи.

## Запуск

Из папки `l3_todo_list`:

```powershell
flutter pub get
flutter run
```

Для браузера:

```powershell
flutter run -d web-server --web-port 8752 --web-hostname 127.0.0.1
```

Открой http://127.0.0.1:8752. Для сохранения веб-задач используй тот же адрес, порт и профиль браузера.
